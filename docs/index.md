# Summary

Open UDC is an proof-of-concept project of Tucson for Everyone to create an open-source version of Tucson's Unified Development Code. While this document is already public, this project seeks to:

  * Facilitate ongoing, continuous improvements to public codes.
  * Improve the gathering and tracking public input.
  * Make city-led code revision projects more effective. 
  * Establish clear decision making records for each proposed change.
  * Maintain a backlog of work to improve outcomes in grant applications.
  * Reduce the time between change adoption and publication from months to minutes.
  * Investigate the incorporation of emerging & innovative technologies.
